# Evaluaciones

Evaluaciones parciales (EP1, EP2, EP3) y evaluación final (EFT).

## Evaluaciones

- **ep1/**: Evaluación Parcial 1
- **ep2/**: Evaluación Parcial 2
- **ep3/**: Evaluación Parcial 3
- **eft/**: Evaluación Final Teórica (si aplica)

## Estructura

Cada evaluación contiene exactamente lo necesario para compilar, ejecutar y revisar la entrega:

```
evaluaciones/
├── ep1/
│   ├── README.md
│   └── src/
├── ep2/
│   ├── README.md
│   └── src/
├── ep3/
│   ├── README.md
│   └── src/
└── eft/
    └── README.md
```

Cada carpeta de evaluación incluye su propio `README.md` con:
- Descripción de requisitos
- Cómo compilar y ejecutar
- Rúbrica de evaluación (si aplica)
