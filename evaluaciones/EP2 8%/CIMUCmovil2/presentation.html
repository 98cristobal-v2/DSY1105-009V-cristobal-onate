Centro de Innovación en Madera (CIM UC)

CIM UC Móvil

Aplicación Android nativa desarrollada para la gestión de proyectos, I+D y transferencia tecnológica en construcción sustentable.

Integrantes: Cristóbal Oñate & Ricardo Almarza
Stack: Kotlin • Jetpack Compose • Room • MVVM

1. ¿Qué construimos y por qué?

Diseñamos y desarrollamos CIM UC Móvil, una app móvil enfocada en resolver la necesidad de difusión y vinculación del Centro de Innovación en Madera. La app permite consultar proyectos en madera masiva (CLT), laboratorios de ensayos, investigadores y publicaciones de forma rápida y sin depender de conexión constante a internet.

💡 Enfoque Práctico

Una interfaz limpia inspirada en Material 3, pensada para que académicos, estudiantes y profesionales de la construcción accedan a información técnica clave al instante.

⚙️ Arquitectura Robusta

Implementamos buenas prácticas de desarrollo nativo Android: separación de capas, persistencia local y programación reactiva.

2. Estructura y Arquitectura (MVVM)

Organizamos el código modularmente para mantener responsabilidades claras y facilitar la escalabilidad:

📦

model

Clases de datos (CimContent) y enums de categorías.

🗄️

data

Entidades Room, DAOs, Base de datos y Repositorio.

⚡

viewmodel

Lógica de negocio y manejo de estado (StateFlow).

🎨

ui

Pantallas en Jetpack Compose (Listas, Detalles, Formularios).

3. Persistencia Local con Room (SQLite)

Para guardar los registros localmente, utilizamos Room con una entidad mapeada y un callback que precarga datos iniciales automáticamente: 

@Entity(tableName = "cim_contents")
data class CimEntity(
    @PrimaryKey val id: String,
    val type: String,
    val title: String,
    val shortDescription: String,
    val areaTematica: String,
    val year: String? = null,
    val status: String? = null
) {
    fun toDomain(): CimContent { ... }
}

El repositorio expone un Flow<List<CimContent>> que actualiza la UI de forma automática ante cualquier cambio en la base de datos.

5. Formularios Validados y Operaciones CRUD

📝 Validación en Tiempo Real

El formulario verifica que campos como el título o la descripción no estén vacíos. Si hay un error, actualiza el estado y muestra un mensaje visual rojo debajo del campo correspondiente antes de permitir guardar en Room.

🔄 CRUD Completo

El usuario puede Listar (con buscador instantáneo), Registrar nuevas iniciativas mediante el FAB (+), Editar fichas existentes y Eliminar registros con diálogo de confirmación.

6. Integración de Recursos Nativos

Aprovechamos las capacidades del dispositivo mediante intents y contratos de Android:

📷
