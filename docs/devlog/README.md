## Formato

Cada entrada semanal contiene:

```markdown
# DevLog · Semana XX

## Objetivo
(Qué se planificó hacer esta semana)

## Avance
(Qué se logró concretamente)

## Bloqueo
(Qué obstáculos se enfrentaron, si aplica)

## Aprendizaje
(Qué se aprendió, descubrimientos técnicos)

## Siguiente
(Qué viene para la próxima semana)
```

## Notas

- No mide horas, no exige textos largos
- Debe ser breve, específico y coherente con el trabajo real
- Refleja el aprendizaje real durante el semestre
