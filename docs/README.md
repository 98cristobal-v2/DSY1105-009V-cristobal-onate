## DevLog

El DevLog registra la evolución semanal del estudiante de forma breve, específica y coherente con el trabajo real.

### Estructura de una entrada DevLog

Cada semana contiene:

- **Objetivo**: Qué se planificó hacer
- **Avance**: Qué se logró concretamente
- **Bloqueo**: Qué obstáculos se enfrentaron (si aplica)
- **Aprendizaje**: Qué se aprendió
- **Siguiente**: Qué viene para la próxima semana
